# 题库刷题系统

这是一个本地运行的题库刷题工具，服务端使用 Go + Gin 编写，前端使用原生 HTML/CSS/JavaScript。系统可以从 PDF 或 DOCX 题库中解析题目，组卷后隐藏答案和解析，答题后再显示判题结果、正确答案和解析。

## 主要功能

- 账号注册、账号数据清空，用户名不允许重复。
- 多题库来源组卷，支持按目录树选择来源和设置题目数量。
- 未完成试卷持久化保存，可继续答题，也可删除试卷。
- 每套试卷可查看本套错题。
- 每个账号独立错题库，错误次数和成功答出次数都会累计。
- 支持刷错题、刷精选错题、疑问标记和刷疑问题。
- 数据持久化到 SQLite，避免浏览器缓存清理导致数据丢失。
- SQLite 驱动使用纯 Go 实现，不依赖 CGO。
- 默认端口为 `16666`。

## 快速启动

```powershell
$env:CGO_ENABLED='0'
go build -o exam-paper.exe ./cmd
.\exam-paper.exe --host 0.0.0.0 --port 16666
```

启动后访问：

```text
http://127.0.0.1:16666/
```

也可以使用项目里的启动脚本：

```powershell
.\start.ps1
```

## Docker Compose

```bash
docker compose pull
docker compose up -d
```

Docker 镜像内不包含 `data` 数据目录，也不包含题库文件。Compose 会挂载：

- `./data:/app/data`
- `./演出协会官方题库题目:/app/演出协会官方题库题目:ro`
- `./演出协会模拟考:/app/演出协会模拟考:ro`

## 注意事项

- 如果 PDF 是扫描图片，当前解析器无法识别图片文字，需要先 OCR 成可复制文本或 DOCX。
- 浏览器会拦截部分不安全端口，例如 `6666`，因此默认端口使用 `16666`。
- 不要手动删除 `data/exam-paper.db`，否则账号、试卷进度和错题库都会丢失。
