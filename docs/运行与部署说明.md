# 运行与部署说明

## 本地运行

推荐直接编译后运行：

```powershell
$env:CGO_ENABLED='0'
go build -o exam-paper.exe ./cmd
.\exam-paper.exe --host 0.0.0.0 --port 16666
```

也可以使用启动脚本：

```powershell
.\start.ps1
```

启动后访问：

```text
http://127.0.0.1:16666/
```

如果需要局域网内其他设备访问，请使用本机局域网 IP，例如：

```text
http://192.168.31.120:16666/
```

## 默认端口

默认端口是 `16666`。浏览器可能会拦截部分不安全端口，例如 `6666`，所以项目不再使用 `6666` 作为默认端口。

## Docker Compose 运行

使用已经发布到 GitHub Container Registry 的镜像启动：

```bash
docker compose pull
docker compose up -d
```

查看日志：

```bash
docker compose logs -f
```

停止服务：

```bash
docker compose down
```

## Docker 挂载规则

镜像内只包含程序、静态页面和说明文档，不包含 `data` 数据目录，也不包含题库文件。

当前 Compose 使用的镜像：

```text
ghcr.io/pika623/exam-paper:latest
```

Compose 会挂载这些宿主机目录：

- `./data:/app/data`：持久化 SQLite 数据库和导入文件。
- `./演出协会官方题库题目:/app/演出协会官方题库题目:ro`：官方题库，只读挂载。
- `./演出协会模拟考:/app/演出协会模拟考:ro`：模拟考题库，只读挂载。

## Linux 构建

```powershell
$env:CGO_ENABLED='0'
$env:GOOS='linux'
$env:GOARCH='amd64'
go build -trimpath -ldflags="-s -w" -o exam-paper ./cmd
```

## 验证命令

```powershell
go test ./...
go build -o exam-paper.exe ./cmd
```
