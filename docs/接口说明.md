# 接口说明

所有接口返回 JSON。错误响应格式：

```json
{
  "error": "错误信息"
}
```

## 账号

### 获取账号列表

`GET /api/users`

返回账号、当前未完成试卷、累计做题数量、错题数量、疑问题数量等摘要信息。

### 注册账号

`POST /api/users`

```json
{
  "name": "账号名称"
}
```

用户名不允许为空，也不允许重复。

### 清空账号数据

`POST /api/users/clear`

```json
{
  "userId": "账号 ID"
}
```

会清空该账号的试卷、答题记录、错题库和疑问标记，不删除账号本身。

## 题库

### 获取题库来源

`GET /api/library`

返回可选题库来源列表，前端按目录树渲染。

### 解析单个题库文件

`GET /api/parse?path=题库路径`

用于解析指定 PDF 或 DOCX 并返回题目预览。

### 导入题库文件

`POST /api/import`

上传 PDF 或 DOCX。导入目录会保存到 `data/imports`，散文件会保存到 `data/uploads`。

### 统计来源题目数量

`POST /api/questions/count`

```json
{
  "sources": ["题库路径1", "题库路径2"]
}
```

## 试卷

### 创建试卷

`POST /api/exams`

```json
{
  "userId": "账号 ID",
  "sources": ["题库路径"],
  "count": 20
}
```

试卷名称格式为：`当前用户名称_组卷时间到秒`。

### 删除试卷

`DELETE /api/exams?userId=账号ID&examId=试卷ID`

删除试卷不会清空用户错题库。

### 获取当前或指定试卷

`GET /api/exams/current?userId=账号ID`

`GET /api/exams/current?userId=账号ID&examId=试卷ID`

### 获取未完成试卷列表

`GET /api/exams/list?userId=账号ID`

### 保存答题

`POST /api/exams/answer`

```json
{
  "userId": "账号 ID",
  "examId": "试卷 ID",
  "questionId": "题目 ID",
  "selected": ["A"],
  "current": 0
}
```

接口会返回是否正确，并在答错时累计错题库次数。

### 保存进度

`POST /api/exams/progress`

```json
{
  "userId": "账号 ID",
  "examId": "试卷 ID",
  "current": 0
}
```

## 错题和疑问题

### 本套错题

`GET /api/exams/wrong?userId=账号ID&examId=试卷ID`

### 错题库

`GET /api/wrong-book?userId=账号ID`

### 精选错题库

`GET /api/featured-wrong-book?userId=账号ID`

精选规则：`错题被答错的次数 - 错题被答对的次数 >= -3`。

### 刷错题

`POST /api/exams/wrong-practice`

```json
{
  "userId": "账号 ID",
  "count": 0
}
```

`count` 为 `0` 时默认使用全部错题。

### 刷精选错题

`POST /api/exams/featured-wrong-practice`

```json
{
  "userId": "账号 ID",
  "count": 0
}
```

### 疑问库

`GET /api/doubts?userId=账号ID`

### 标记或取消疑问

`POST /api/doubts/toggle`

```json
{
  "userId": "账号 ID",
  "questionId": "题目 ID",
  "marked": true
}
```

### 刷疑问题

`POST /api/exams/doubt-practice`

```json
{
  "userId": "账号 ID",
  "count": 0
}
```
