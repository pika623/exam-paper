# 开发说明

## 技术栈

- 后端：Go + Gin。
- 数据库：SQLite，驱动为 `modernc.org/sqlite`，不依赖 CGO。
- 前端：原生 HTML/CSS/JavaScript。
- 解析：PDF 使用 `rsc.io/pdf`，DOCX 使用 zip + XML 解析。

## 常用命令

运行测试：

```powershell
go test ./...
```

编译 Windows 可执行文件：

```powershell
$env:CGO_ENABLED='0'
go build -o exam-paper.exe ./cmd
```

编译 Linux 可执行文件：

```powershell
$env:CGO_ENABLED='0'
$env:GOOS='linux'
$env:GOARCH='amd64'
go build -trimpath -ldflags="-s -w" -o exam-paper ./cmd
```

构建 Docker 镜像：

```bash
docker compose build
```

## 后端开发约定

- 新增 HTTP 接口时，先在 `internal/controller` 中实现控制器方法，再到 `internal/api/router.go` 注册路由。
- 新增数据库读写逻辑时，放到 `internal/repository`。
- 题库缓存、题目查找、题库同步逻辑放到 `internal/service/questionbank`。
- PDF/DOCX 解析逻辑放到 `internal/service/parser`。
- 通用工具函数放到 `internal/utils`。
- 接口结构体和业务模型放到 `internal/model`。

## 数据安全约定

- 不要在代码中删除整个 `data` 目录。
- 不要把 `data/exam-paper.db` 打入 Docker 镜像。
- 不要把题库目录打入 Docker 镜像，题库目录通过 Compose 只读挂载。
- 需要测试空数据库时，优先使用临时目录，不要直接清空当前用户数据。

## 前端开发约定

- API 路径保持兼容，避免影响现有页面逻辑。
- 导入区目前是临时屏蔽状态，恢复时要同时检查文件上传接口。
- 题库目录树的展开/收缩状态和勾选状态需要分开处理，避免勾选时自动展开目录。
